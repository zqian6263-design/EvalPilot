## 作品详细描述

EvalPilot 是面向 AI 应用发布流程的回归评测与自主发布质量官。它解决模型、Prompt、检索、记忆或工具链更新后“普通问答仍然通过，却悄悄破坏关键能力”的发布风险：系统首先让 baseline 与 candidate 在同一组匹配场景上运行，使用控制组、配对置信区间和效应量区分真实回归、测试难度变化与采样噪声；确认回归后，自主调查会生成风险假设、召回历史事故、追加探查，并通过反事实重放禁用可疑变更，测量失败是否真实恢复。最终，系统输出 BLOCK / REVIEW / ALLOW 发布决策、根因、修复建议、可下载证据报告，以及 0 / 1 / 2 机器退出码，直接接入 CI/CD 与 Pull Request 发布门禁。当前公开 Haystack 案例中，26 个匹配场景和 18 个控制组确认 8 个阻断回归：关闭压缩层恢复 7 个条款/流程问题，恢复安全护栏消除 1 个凭证泄露问题；4 类 OOD 干预通过 HTTP 实测确认根因。模型可以规划实验和解释证据，但所有干预必须通过白名单校验，实测结果不能被模型覆盖。系统默认离线可复现，并已在 DeepSeek V4 Pro Live 模式完成 52 次 Judge 调用、78,695 tokens 和完整成本测量。

## 一句话版本

EvalPilot 用匹配评测、统计置信和反事实重放，把 AI 版本变化变成可验收、可阻断、可追溯的发布决策。

## 五维要点

- 技术可行性：FastAPI + React + SQLite 可运行 MVP，一条命令部署，公开 HTTP SUT，离线回放和故障显式失败均已验证。
- 市场可行性：定位发布质量门禁而非另一个评测看板；已有公开付费品类、公开采用信号、CI 集成、成本测量和清晰商业模式假设。
- 综合创新性：核心不是原始分数对比，而是匹配因果比较、配对不确定性和可执行反事实根因重放。
- AI 大模型结合：DeepSeek V4 Pro 负责假设、受约束规划、Judge 和报告解释；确定性引擎掌握分数、证据和发布结论。
- 赛道维度：自然语言目标 -> 自主规划 -> 工具行动 -> 证据交付 -> 发布门禁 -> 回归记忆，端到端闭环已实现。
