## 作品详细描述

EvalPilot 是面向 AI 应用发布流程的回归评测与自主发布质量官。它解决模型、Prompt、检索、记忆或工具链更新后“普通问答仍然通过，却悄悄破坏关键能力”的发布风险：系统首先让 baseline 与 candidate 在同一组匹配场景上运行，使用控制组、配对置信区间和效应量区分真实回归、测试难度变化与采样噪声；确认回归后，自主调查会生成风险假设、召回历史事故、追加探查，并通过反事实重放禁用可疑变更，测量失败是否真实恢复。最终，系统输出 BLOCK / REVIEW / ALLOW 发布决策、根因、修复建议、可下载证据报告，以及 0 / 1 / 2 机器退出码，直接接入 CI/CD 与 Pull Request 发布门禁。

评测对象不限于自带 fixture。当前仓库包含四个真实适配器，全部通过真实边界测量：公开 Haystack HTTP SUT（26 个匹配场景 + 18 个控制组确认 8 个阻断回归，关闭压缩层恢复 7 个条款/流程问题，恢复安全护栏消除 1 个凭证泄露问题，另有 4 类 OOD 干预通过 HTTP 实测确认根因）；公开 mem0 浏览器任务形态（3 次浏览器反事实重放，两臂均真实执行，累计 18 张截图与 18 条动作轨迹）；第三方 MCP Python SDK 回顾（3 个协议回归、3 个控制，3 次 HTTP 重放实测恢复）；以及外部团队接入模板（`integrations/sut_template`，8 个匹配场景确认 5 个回归、3 个对照不变，5 次实测重放，16 条 SUT trace，结论 BLOCK / CRITICAL）。第三方接入由 `scripts/validate-sut.ps1` 做 28 项契约校验，并用 `schemas/workload.schema.json` 校验工作负载，30 分钟接入清单见 `docs/P5_SUT_ONBOARDING.md`。

在产品可信度上，系统坚持“预测不等于实测”：反事实结果必须来自真实重放（每条 counterfactual 需有重放 trace 与引擎生成的 rationale），外部服务自定义的干预名会被原样下发并测量，而不是退化成离线预测；外部 SUT 不可用且缓存缺失时显式失败，不静默回退 mock。发行侧提供可校验源码包（SHA-256、文件清单，并在全新解压目录中重新安装依赖、启动前后端完成健康检查）。模型可以规划实验和解释证据，但所有干预必须通过白名单校验，实测结果不能被模型覆盖。系统默认离线可复现，并已在 DeepSeek V4 Pro Live 模式完成 52 次 Judge 调用、78,695 tokens 和完整成本测量。

## 一句话版本

EvalPilot 用匹配评测、统计置信和反事实重放，把 AI 版本变化变成可验收、可阻断、可追溯的发布决策。

## 五维要点

- 技术可行性：FastAPI + React + SQLite 可运行 MVP，一条命令部署，四个真实适配器完成端到端实测（HTTP SUT、浏览器任务、第三方 MCP、外部接入模板），离线回放、故障显式失败与可校验发行包均已验证。
- 市场可行性：定位发布质量门禁而非另一个评测看板；已有公开付费品类、公开采用信号、CI 集成、成本测量和清晰商业模式假设。
- 综合创新性：核心不是原始分数对比，而是匹配因果比较、配对不确定性和可执行反事实根因重放；并明确区分“实测恢复”与“离线预测”，预测结果不会被展示为实测结论。
- AI 大模型结合：DeepSeek V4 Pro 负责假设、受约束规划、Judge 和报告解释；确定性引擎掌握分数、证据和发布结论。
- 赛道维度：自然语言目标 -> 自主规划 -> 工具行动 -> 证据交付 -> 发布门禁 -> 回归记忆，端到端闭环已实现，并可通过接入模板扩展到外部团队自己的服务。

## 提交边界

- 不声称已有付费客户、真实访谈或市场份额。
- 不把 roadmap 写成已实现能力：真实客户生产部署、多租户权限和第二模型供应商对照不在本仓库验证范围内。
- `$0.264697` 是已记录场景与价格假设下的实测运行成本，不是通用生产价格。
- Haystack 回归是受控 candidate patch，不代表上游项目本身存在该缺陷。
- 浏览器验收依赖本机 Chrome/Edge；无浏览器环境会明确失败，不会降级为预测结论。
