# EvalPilot

**AI 应用回归评测数字员工**。输入产品需求与版本变更，自动规划测试、调用工具执行、采集证据、识别真实能力回归，并输出可验收的评测报告。

## 当前里程碑

- 赛道：AI+超级智能体（高校组）
- 初赛截止：2026-09-19
- MVP 范围：企业知识库问答 / 智能客服
- 要求：可运行、可演示、有证据链、有可复现评测指标

## 仓库结构

```text
backend/   FastAPI、运行编排、存储、工具层
frontend/  React + Vite 演示控制台
docs/      产品、接口与协作约定
scripts/   启动、初始化和验收脚本
```
