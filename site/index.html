AI 应用回归评测与自主发布质量官

让每一次版本发布，都有可验收的质量证据。

版本更新后，AI 应用可能在速度提升、普通问答通过的同时，悄悄破坏条款、权限或安全护栏。EvalPilot 用匹配场景、统计置信和反事实重放，把“感觉变差”变成明确发布决策。

问题

分数变化不等于真实回归。

关键能力会静默退化

新版本可能更快，普通问题仍然通过，却丢失退款条款、破坏租户隔离或泄露凭证。

单次分数无法证明因果

测试集变难、采样波动和版本差异都可能导致误判，没有控制组就没有可信结论。

报告失败不等于能发布

团队仍要知道哪个变更造成失败、修复后是否恢复，以及问题是否足以阻断发布。

闭环

从版本变更到发布决策，任务完整接管。

模型负责规划和解释；实测分数、证据、根因结论和发布决策由确定性引擎掌握。

01

匹配回归评测

baseline 与 candidate 使用同一组 26 个匹配场景和 18 个控制组。

02

统计置信与功效

输出效应量、配对置信区间、功效诊断与明确 verdict，避免把噪声说成回归。

03

反事实根因重放

受约束模型规划候选实验，引擎执行白名单干预，通过真实恢复情况确认根因。

04

发布质量门禁

输出 BLOCK / REVIEW / ALLOW、Markdown 报告、JUnit、SARIF、PR 回写和退出码。

架构

自主执行，但结论不可被模型覆盖。

需求与版本变更自然语言目标
→
匹配场景规划正常 / 边界 / 对抗
→
外部 SUT 执行HTTP / 工具 / 证据
→
统计判定配对区间 / 控制组
→
自主调查假设 / 记忆 / 探查
→
反事实重放白名单干预 / 实测
→
Release Gate报告 / CI / PR
故障显式失败

外部 SUT 不可用时不会静默回退 mock，避免把基础设施故障伪装成评测结果。

模型边界受控

LLM Judge 可替换为确定性实现；规划和评审调用受 token 与调用次数预算约束。

默认离线可复现

演示无需 API Key；Live 模式通过 OpenAI-compatible 接口接入 DeepSeek V4 Pro。
