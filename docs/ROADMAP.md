# 8-Day Roadmap

## Fixed date

Submission deadline: **2026-09-19**. Do not optimize for features that cannot be shown before that date.

## Day 1-2: contract and skeleton

- Lock domain model and API shapes.
- Create runnable backend and frontend shells.
- Seed one deterministic demo project and two versions.

## Day 3-4: core execution

- Planner creates task cases from the project brief.
- Executor runs HTTP and browser/file tools.
- Persist evidence and task state.
- Produce progress events.

## Day 5: evaluation

- Deterministic checks for citation, refusal, format, and factual consistency.
- LLM judge with explicit rubric and JSON output.
- Matched-case causal comparison and repeated sampling.

## Day 6: demo experience

- Dashboard for run progress, cases, evidence, scores, and findings.
- One-click seeded demo.
- Report export.

## Day 7: validation

- End-to-end test.
- Deliberately regress one version and verify detection.
- Record 2-3 minute video.
- Prepare PPT, README, and screenshots.

## Day 8: submission

- Freeze code and data.
- Run clean setup from a fresh shell.
- Submit early on 2026-09-19.

## Prioritization rule

A narrow working loop beats a broad unfinished platform. If time is short, keep the seeded knowledge-base QA scenario and remove optional integrations.
