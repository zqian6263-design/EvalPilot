## Title

EvalPilot｜AI应用回归评测数字员工｜自主规划与反事实根因定位

## Description

EvalPilot 是面向 AI 应用发布流程的回归评测数字员工。它对比 baseline 和 candidate，自动规划匹配测试、调用外部工具、采集证据；确认回归后通过受约束的模型规划和反事实重放定位根因，最终输出 BLOCK / REVIEW / ALLOW 发布决策、可下载证据报告和 CI/CD 退出码。

演示覆盖 26 个匹配场景和 18 个控制组，准确识别 8 个发布阻断回归。模型可以规划下一步实验，但每个选择都必须通过可执行干预白名单校验，并由引擎真实执行和测量，不能覆盖分数或结论。

验证证据包括：

- 公开开源 Haystack HTTP SUT 端到端评测；
- 同版本对照 0 回归、正式对比 8 个回归；
- 8 次 HTTP 反事实重放；
- 离线缓存一致复现与 SUT 故障明确失败；
- 52 次 Judge 调用和 78,695 tokens 的完整成本测量；
- 确定性规划与 DeepSeek V4 Pro 规划对照。
